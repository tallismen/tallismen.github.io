# DesignLama

Portfolio site for [www.designlama.nl](https://www.designlama.nl), built with **Vite + React** (plain JavaScript) and deployed to GitHub Pages.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` / `master` run [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

In the GitHub repo: **Settings → Pages → Source → GitHub Actions**.
